# ava_webI

Atividades práticas em PHP - Programação procedural, formulários, sessões e cookies.

## Estrutura

- `atividade1/` — Sistema de Classificação Acadêmica
- `atividade2/` — Simulador de Cadastro via Formulário (POST)
- `atividade3/` — Sistema de Login com Área Restrita (sessões)
- `atividade4/` — Controle de Acesso com Cookies
- `atividade5/` — Desafio Integrador (login + cadastro + validação)

## Como rodar no Codespace

1. Abra o terminal do Codespace.
2. Inicie o servidor embutido do PHP na raiz do projeto:

   ```bash
   php -S localhost:8000
   ```

3. O Codespace vai mostrar um aviso para abrir a porta 8000 no navegador — clique em **Open in Browser**.
4. Acesse a página inicial (`index.php`), que traz o menu com todas as atividades.

> Login de teste usado nas atividades 3 e 5: usuário `admin`, senha `1234`.
